# Sync with Project Context

Read SESSION_CONTEXT.md to understand current project status, then provide a brief summary of:

## Required Reading
- Current issues being investigated
- Recent fixes and implementation status
- Next steps or pending tasks
- Git status and modified files
- Investigation timeline and findings

## Context Maintenance Instructions
**CRITICAL**: Always maintain SESSION_CONTEXT.md throughout the session:

### When to UPDATE SESSION_CONTEXT.md:
- At the start of any new investigation
- When discovering root causes of issues
- After implementing fixes or changes
- When completing tasks or resolving issues
- When finding new issues or errors
- At major milestones in complex tasks

### What to DOCUMENT:
- Investigation progress and findings
- Root cause analysis results
- Implementation details and file changes
- Status updates (pending → in_progress → completed)
- Error analysis and error messages
- Solutions attempted and their outcomes
- Dependencies between issues
- Next steps and recommendations

### Format Requirements:
- Use clear headings and status indicators (✅ ❌ 🔄)
- Include file paths and line numbers for code references
- Maintain chronological order of events
- Update dates and current status section
- Document both successful and failed attempts

**Remember**: SESSION_CONTEXT.md is the project memory - always read it first, update it as you work, and ensure continuity for future sessions.
